# 🌍 Travel Recommendation Web Application

## 📖 Overview
The **Travel Recommendation Web Application** helps users explore beautiful destinations around the world.  
It provides recommendations for **beaches**, **temples**, and **countries**, each with images and descriptions fetched from a local JSON API.

---

## 🧱 Features
- 🏠 **Home Page:** Introduction to TravelBloom and a search bar for destinations.  
- 👥 **About Us Page:** Company mission and team member details.  
- 📬 **Contact Us Page:** Email form for user inquiries.  
- 🔍 **Search Functionality:** Type “beach,” “temple,” or “country” to view curated recommendations.  
- 🖼️ **Dynamic Display:** Results appear in a responsive grid layout with images and descriptions.  
- 🧹 **Clear Button:** Resets search input and results instantly.

---

## 🧩 Technologies Used
- HTML5  
- CSS3  
- JavaScript (ES6)
